# What existed before the hackathon

The hackathon rules ask entrants to show clearly what was built during the event. Witness is new. It runs inside
LoWisa, which existed before 27 Oct 2026. The parts below were built earlier; their code is not in this repository.

| Existing part | What Witness uses it for |
|---|---|
| LoWisa phone app (React Native) and desktop IDE | Where the Witness screens and the Exam Desk view are shown |
| Accounts, credits, metering, school wallet | Who may use Witness and who pays for each model call |
| Master any topic level builder | Builds each mastery level to the same standard as every LoWisa level. Witness supplies the new input: the failed question, the diagnosis, the student's own working and the teacher's focus note. |
| Level contents (lessons, beats, first look, halfway twist, main run, Lo asks, Insight episode, flashcards, A4 notes) | What a mastery level contains |
| Scene player and lesson player | Play the mastery level on the phone |
| Lo's voice | Speaks the examiner's questions |
| School dashboard and roles | Teachers, classes and who sees which student |
| Earlier exam photo capture and marking (other providers) | Replaced in Witness by video, SAM 3.1 and Muse Spark |
