# Screens

Screenshots of the built product, taken from the live edge during the event: `desk-*` is the teacher's Exam Desk (in
LoWisa's desktop app), `phone-*` is the learner's side (in LoWisa's phone app). The papers on them are sample papers
made for the demo, never a real student's. README section 3 walks through the ones the film leaves out; the film uses
`phone-lo-asks-first.png`, `desk-fingerprint-c-after-lo-asked.png`, `phone-recheck-right.png` and
`desk-turned-around.png`.
