mode was added to it: exactly one level of three lessons for one failed question, written with `MASTERY_RULE`, then
played by Muse Wonder as both students, and written again with what the check found, up to the set number of times.

[`course-mastery-excerpt.txt`](course-mastery-excerpt.txt) holds the 95 lines of that file written during the event,
exactly, each with the date git blame gives it and its line number. The LoWisa code around them existed before the
event and stays private; where it is left out, the excerpt shows "...".

What it calls on this side: the design route (`/api/witness/design`, `witness_api`), and the self-check (`/api/witness/check`,
`witness_check`, Muse Wonder).
